idevice-rs

WebUSB (Chromium) can open the Apple mux pipe and complete a pseudo-TCP handshake to lockdownd. Pairing, TLS, battery, diagnostics, and crash reports run on the host via the idevice CLI through POST /api/cli (inline Python in scripts/serve.sh). From a terminal use cargo run -p idevice-cli -- … (see README.md).

WebUSB

Requires a secure context (HTTPS or localhost) and a user gesture. On Linux you may need to stop usbmuxd so the browser can claim the interface.
